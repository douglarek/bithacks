# 13 · 整数 log2 / log10（最高置位）

**头文件：** [`log2.hpp`](../include/bithacks/log2.hpp)

`floor(log2(v))` = 最高置位的下标（从 0 起）。`v==0` 本教程返回 `-1`。

## 方法

1. **朴素**：右移计数  
2. **二分/折半**：测高半是否非零  
3. **查表**：找最高非零字节再查 256 表  
4. **De Bruijn**：填满低位后乘常数，查 32 项表  
5. **float 指数**：转 `float` 读指数域（精度限制）  
6. **log10**：由 log2 近似再按 `10^k` 表校正，或级联比较  

## 标准库

```cpp
int lg = std::bit_width(v) - 1;           // v > 0
int lg2 = 31 - std::countl_zero(v);       // 32-bit, v > 0
```

## float 相关

- `log2_of_float_bits`：直接解读 IEEE754 指数  
- `log2_pow2r_root_float(f, Pow2RootDepth{r})`：对 `2^r` 次根的 log2 近似为指数右移 `r` 位
