# 11 · 位序列反转

**头文件：** [`reverse.hpp`](../include/bithacks/reverse.hpp)

## 方法

| 方法 | 说明 |
|------|------|
| 朴素循环 | 逐位取出 |
| 字节表 | 256 项反转再拼接 |
| 字节 3/4/7 ops | 乘法魔法（64 位或 32 位） |
| 并行交换 | 交换邻位→2 位组→半字节→字节→半字 |

并行 32 位：

```cpp
v = ((v >> 1) & 0x55555555) | ((v & 0x55555555) << 1);
v = ((v >> 2) & 0x33333333) | ((v & 0x33333333) << 2);
// ... 4, 8, 16
```

## 标准库现状

- `std::byteswap`（C++23）：只反转**字节序**，不反转比特  
- 编译器内建：`__builtin_bitreverse32` 等
