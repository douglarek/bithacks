**头文件：** [`modulus.hpp`](../include/bithacks/modulus.hpp)

## 对 2 的幂取模

```cpp
v % (1 << s)  ==  v & ((1 << s) - 1)
```

## 对 Mersenne 数 `(1<<s)-1` 取模

类似「数位和」：把 `v` 按 `s` 位一组相加，重复直到落入范围，再把等于模数的情况收成 0。

```cpp
// 概念上
while (v > d) {
  m = 0;
  while (v) { m += v & d; v >>= s; }
  v = m;
}
return v == d ? 0 : v;
```

当除法指令很慢、而 `s` 固定时，这种折叠有历史价值。今天编译器对常量模数通常会强度削弱成乘高位，优先写 `v % d`。
