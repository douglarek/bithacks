# 00 · 导论：为什么要玩转比特

本教程改编自 [Bit Twiddling Hacks](https://graphics.stanford.edu/~seander/bithacks.html)，用 **C++23** 重写全部技巧，并配中文推导。

## 位运算能做什么

在图形、压缩、哈希、棋盘、网络协议、嵌入式等场景里，常需要：

- 无分支地算符号、绝对值、min/max
- 数有多少个 1（popcount）、奇偶性、最低/最高置位位置
- 把两个坐标交错成 Morton 码
- 在一个 32/64 位字里同时检查多个字节

很多操作今天已有硬件指令和标准库（`std::popcount` 等），但理解这些技巧仍然有价值：

1. 看懂老代码与编译器输出  
2. 在没有对应指令的目标上写出正确快速实现  
3. 建立「掩码、折叠、隔离最低位」的直觉  

## 操作计数（Operation Counting）

原站用「每个 C 运算符算 1 次操作」来粗略比较算法。中间赋值不计数。这只是近似：

- 真实代价取决于指令延迟、吞吐、寄存器压力、缓存
- 分支误预测可能比多几次算术更贵
- **最终以基准测试为准**

本教程在文档中保留「大约多少步」的描述，但不替代 profiling。

## 现代 C++ 对照表

| 经典技巧 | C++20/23 `<bit>` |
|----------|------------------|
| 是否 2 的幂 | `std::has_single_bit` |
| 上取整到 2 的幂 | `std::bit_ceil` |
| 下取整到 2 的幂 | `std::bit_floor` |
| 最高位置位相关 | `std::bit_width` / `std::countl_zero` |
| 尾随零 | `std::countr_zero` |
| 置位数 | `std::popcount` |
| 类型双关 | `std::bit_cast`（勿用指针强转） |

教程会**同时**给出手写实现与标准库对照，方便你在「理解原理」和「生产代码」之间切换。

## 可移植性要点（贯穿全书）

1. **有符号右移**：C/C++ 对负数算术右移 historically 是 implementation-defined；C++20 起对补码算术右移有更清晰规定，但仍建议用可移植写法教学。  
2. **`INT_MIN` 的绝对值**：有符号类型装不下 `|INT_MIN|`，应返回 `unsigned`。  
3. **移位量**必须落在 `[0, width)`，否则未定义行为。  
4. **类型双关**：用 `std::bit_cast`，不要 `*(float*)&x`。
